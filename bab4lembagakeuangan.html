🎯 Tujuan
Kumpulkan properti sebanyak mungkin dengan menjawab soal dengan benar sebelum giliran habis.
🎮 Mode Permainan
  1. Solo: main sendiri, kumpulkan properti.
  2. Duel: 2 pemain bergantian, siapa paling banyak properti menang.
  3. Duel Tim: sama seperti duel, tapi nama pemain jadi Tim Biru vs Tim Merah.
🎲 Langkah Permainan
  1. Klik tombol Lempar di tengah papan.
  2. Token berjalan mengelilingi papan.
  3. Mendarat di petak properti → muncul soal.
  4. Jawab benar → beli properti. Salah → denda Rp200.000.
🔥 Streak jawaban benar berturut-turut (muncul di sebelah kiri dadu).
